# Task Distribution

[🇫🇷 French version](french-version/task-distribution.md)

Plan of the 8 weekly sessions dedicated to the project.
This plan may change slightly depending on the delivery time of the ordered parts and on the difficulties we run into.

| Session | Adrien | Redha |
|---|---|---|
| 1 | *Together:* choice of a board cut to the right dimensions. Then outline of the pinball machine; positioning test of a flipper prototype, to install the motors in the next session; getting started with the infrared sensors. | *Together:* choice of a board cut to the right dimensions. Then pencil sketch of the pinball machine on the board; position of the launch lane and design of the launcher. |
| 2 | Installation of the flippers with their motors (+ code), then of a few infrared sensors. | Building the slingshots + operating test. |
| 3 | Installation of the bumpers. | Continued installation of the slingshots + installation of the servomotor that brings the ball back to the launch lane. |
| 4 | Building the targets and adding points. | Continued work on the bumpers. |
| 5 | Setup and installation of the LCD screen to display the player's score. | Installation of the LEDs, deciding which LEDs to light depending on the triggered sensors. |
| 6 | Installation of a part with a servomotor that releases more balls from the top of the pinball machine when Multiball mode is triggered. | Building and installing ramps. |
| 7 | Building the wheel of fortune, triggered for example when the 3 targets are hit, to win bonuses or start Multiball mode. This step will be done only if time allows (that is, if all the components designed and installed in the previous sessions work correctly). | Start of the decoration, code debugging. |
| 8 | Debugging, finishing touches and decoration. | Debugging, finishing touches and decoration. |
